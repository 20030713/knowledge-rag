# RAG 回归评测语料

该目录提供一套可重复导入的最小评测基线，包含三个主题文档和 15 个问题：12 个可回答问题、3 个不可回答问题。

- `expense-policy.md`：精确金额、时限、审批条件。
- `incident-runbook.md`：等级、时序、操作步骤与禁止事项。
- `rag-engineering-guide.md`：RAG 清洗、切分、混合召回、拒答与评测规范。
- `eval-cases.json`：期望答案、关键词、来源文件和拒答标记。

语料刻意包含相似数字、相近的时限表达和跨主题术语，用于检测错误引用与“永远返回 TopK”问题。它只用于工程回归，不代表真实业务数据。
